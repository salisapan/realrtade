# Contrast pairs and metamorphic checks (lab)

Glance closes open loops. Gmail is where it starts today.

- `pairs-v1.cjs`: 18 minimal pairs (EN and HE), each differing in one fact (ask against a confirmed amount, exact against approximate amount, To against Cc, named against group greeting, ask against FYI, future promise against past report, meeting with and without a time, save with and without an attachment, dated against vague note to self, undated ask against statement, work against reply, newsletter footer, holiday promise). A pair passes only when both rows are right. Written by Claude from `docs/glance-ai/model-conventions.md`; synthetic, NOT owner-verified; the "soft" rows encode a convention the owner has not confirmed.
- `run.cjs`: runs the pairs through the tip rules engine. `baseline-2026-11-11.json`: **9 of 18 pass; 6 hard failures**, and each one is an open or optional convention, not an engine defect: a confirmed amount with no ask read as a task (C-1, EN and HE: the owner decided silence, built as the off-by-default option `confirmedAmountSilent`), a Cc-only reader greeted by name still offered a draft (C-12, a profile feature the owner left as is), a vague note to self read as a task (C-10, lab), an ask for work answered with a reply draft (C-7, open for the owner), and a promise «לפני החג» left silent (C-3, which waits on C-18, a reader's promise with no date). Two earlier "failures" were wrong expectations of mine and were fixed: a file noun ("signed form", «החוזה החתום») sends the ask to the engine's file chain by design, and an approval ask with a deadline is a task by the owner's decision (C-15); a note-to-self row was also built with the wrong sender.
- `test-ratchet.cjs`: a pair that passed in the baseline must still pass.
- `../metamorphic/run.cjs`: meaning-preserving edits (greeting and sign-off, "Re:" subject, mobile signature, spacing and doubled punctuation) on 600 test rows. **CORRECTION 2026-11-11: the first reading, "0 flips of 600 on every edit", was void.** An edit set `body` but the engine reads `cleanBody` when a row has one, so the edit never reached it (and the baseline used the un-normalised row). Fixed (`mk` sets both, the baseline is the same row normalised). Real reading, 600 rows, 10 edits: greeting and sign-off flips 25 rows (4.2%, 24 of them silent to act: a mail that is silent without a greeting is offered once it opens with «Hi Sali»); **doubling the spaces flips 62 rows (10.3%, 53 of them act to silent): the engine's patterns assume single spaces**; doubled final punctuation 1; a thanks line, a signature block, a quoted history, an emoji tail 1 to 2 each (about 0.3%); a Re: subject, trailing lines, CRLF line ends and non-breaking spaces 0. A flip is a candidate defect, not a label.

Models are not scored on the pairs yet: a model needs the pair rows exported through the dataset pipeline (`train/export-features-v2.cjs`) and, for a model with the lab's frame features, a JS runtime that knows them.
