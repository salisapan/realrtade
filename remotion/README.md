# Flow Promo — Remotion Project

A 10-second, 4K (3840×2160 @ 60fps) promo video for **Flow — Cognitive
Workflow Engine**, built with [Remotion](https://www.remotion.dev).

## Composition

- `FlowCognitiveOS` — `src/Root.tsx` registers the composition and renders
  `FlowPromo` (`src/FlowPromo.tsx`), which animates the Flow logo, tagline,
  feature highlights, and closing lockup.

## Usage

```sh
npm install
npm start          # opens Remotion Studio for previewing/editing
npm run build       # renders out/flow-promo.mp4
```
