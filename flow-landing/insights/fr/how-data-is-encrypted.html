Sécurité des données

Comment vos données sont chiffrées

« Chiffré » figure sur toutes les pages sécurité. Ce qui compte, c’est où les données sont chiffrées, avec quelles clés, qui les détient, et ce qui reste en clair pendant le traitement.

31 août 2026·3 min de lecture

En bref

  • En transit : TLS 1.3 est la norme actuelle pour les données qui circulent sur un réseau.
  • Au repos : AES est le chiffrement de référence ; la gestion des clés fait la différence.
  • Pendant le traitement : les données sont en général déchiffrées, d’où l’importance du lieu de traitement.

En transit

Les données qui circulent entre votre structure et un service doivent passer par TLS. La version 1.3, définie par l’IETF dans la RFC 8446, a supprimé des options anciennes et plus faibles. Demandez quelles versions un fournisseur accepte, et pas seulement s’il utilise TLS.

Au repos

Les données stockées sont le plus souvent chiffrées avec AES, la norme publiée par le NIST sous le nom FIPS 197. Le chiffrement lui-même est rarement le point faible. Les clés, si.

Les clés décident de tout

Le NIST SP 800-57 décrit comment les clés doivent être générées, conservées, renouvelées et détruites. Questions utiles :

  • Qui peut utiliser les clés qui protègent vos données, et cet accès est-il journalisé ?
  • Les clés sont-elles séparées par client, ou partagées ?
  • Peut-on révoquer une clé, et qu’advient-il alors des données ?

Beaucoup de systèmes utilisent le chiffrement par enveloppe : des clés de données chiffrent les données, et une clé maîtresse, conservée dans un service de clés dédié, chiffre les clés de données.

Pendant le traitement

Pour traiter des données, un système doit en général les déchiffrer en mémoire. Le chiffrement au repos et en transit ne couvre pas ce moment. Deux choses réduisent l’exposition : envoyer moins de données sensibles dès le départ, et les traiter sur du matériel que vous maîtrisez.

Dans Flow

Dans le cloud de Flow, les données sensibles sont masquées avant tout traitement. Avec Flow-Edge ou Flow-Onprem, le traitement a lieu sur le poste du collaborateur ou sur un serveur dans vos locaux, et le contenu n’est déchiffré que là. Demandez-nous, comme à tout fournisseur, les détails par écrit.
