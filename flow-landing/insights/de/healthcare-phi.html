Gesundheitswesen

KI im Gesundheitswesen: wo Patientendaten verarbeitet werden

Für eine Praxis oder einen Krankenversicherer ist die erste Frage an ein KI-Tool nicht, was es kann. Sondern wohin geschützte Gesundheitsdaten gehen, während es das tut.

28. Oktober 2026·3 Min. Lesezeit

Kurz gesagt

  • Nur das Minimum an Gesundheitsdaten nutzen und weitergeben, das eine Aufgabe braucht.
  • Für De-Identifizierung gibt es festgelegte Methoden; Namen entfernen allein genügt nicht.
  • Der Verarbeitungsort ist eine Gestaltungsentscheidung, je Prozess zu treffen.

Das erforderliche Minimum

Nach der HIPAA Privacy Rule in den USA müssen erfasste Stellen sich angemessen bemühen, geschützte Gesundheitsdaten auf das Minimum zu beschränken, das für den Zweck einer Nutzung, Weitergabe oder Anfrage nötig ist (45 CFR 164.502(b)). Für Automatisierung heißt das: Eine Terminaufgabe braucht keine Diagnose, eine Abrechnungsaufgabe keine Behandlungsnotizen.

De-Identifizierung

HIPAA legt in 45 CFR 164.514 zwei anerkannte Methoden fest: das Entfernen einer definierten Liste von Identifikatoren oder eine dokumentierte Feststellung durch eine qualifizierte Expertin. Namen in einer E-Mail zu maskieren hilft, ist aber für sich genommen keine De-Identifizierung im rechtlichen Sinn.

Wo verarbeitet wird

  • In einem Cloud-Dienst mit Maskierung werden identifizierende Angaben vor der Verarbeitung ersetzt.
  • Auf den Rechnern der Mitarbeitenden oder einem Server im Haus geht der Inhalt nicht in eine externe Cloud.
  • In beiden Fällen werden Zugriffe, Freigaben und Protokolle festgelegt, bevor der erste Patientendatensatz berührt wird.
