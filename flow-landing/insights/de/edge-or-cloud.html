Architektur und Sicherheit

Edge oder Cloud? So entscheiden Sie

Die Wahl zwischen Cloud und lokaler Verarbeitung wird oft als Tempo gegen Sicherheit dargestellt. Ein besserer Ausgangspunkt sind die Daten: was sie sind, wer sie sehen darf und wohin sie gelangen dürfen.

31. August 2026·3 Min. Lesezeit

Kurz gesagt

  • Bei den Daten und den Pflichten beginnen, die an ihnen hängen.
  • Maskierung in der Cloud senkt die Exposition; lokale Verarbeitung erspart den Weg nach draußen.
  • Freigaben und Protokolle sollten in jedem Setup gleich funktionieren.

Zuerst drei Fragen

  • Welche Daten berührt dieser Prozess: Mandantennamen, Ausweisnummern, Gesundheits- oder Finanzdaten?
  • Schränken Verträge, Berufsrecht oder Aufsicht ein, wo sie verarbeitet werden dürfen?
  • Wer im Haus kann Hardware betreiben und warten, und wer möchte das lieber nicht?

Die drei Setups von Flow

  • Cloud mit Maskierung: die dedizierte, gesicherte Cloud von Flow. Sensible Daten werden vor jeder Verarbeitung maskiert.
  • Flow-Edge: Verarbeitung auf dem eigenen Rechner des Mitarbeiters. Die Daten bleiben auf diesem Rechner. Geeignet für Unternehmen, die keinen eigenen Server betreiben möchten, sofern die Rechner der Mitarbeitenden über geeignete Hardware verfügen.
  • Flow-Onprem: ein dedizierter Server im Netzwerk des Unternehmens. Die Daten gehen nicht in eine externe Cloud.

Was jedes Setup abwägt

Maskierung verringert, was ein Anbieter sehen kann, ersetzt aber keine Architektur: Wenn Daten im Haus bleiben müssen, nutzen Sie Flow-Edge oder Flow-Onprem. Lokale Setups verlagern die Verantwortung für Gerät, Updates und physische Sicherheit ins Unternehmen. Artikel 25 DSGVO verlangt Datenschutz durch Technikgestaltung und datenschutzfreundliche Voreinstellungen, praktisch also: das Setup je Prozess wählen, nicht eines für alles.

Ein Unternehmen, mehr als ein Setup

Eine Kanzlei kann die Terminplanung in der Cloud mit Maskierung betreiben und Mandantenakten auf Flow-Onprem halten. Freigaben, Berechtigungen, Protokolle und Undo funktionieren in allen drei gleich. Ein Umzug ändert also, wo ein Prozess läuft, nicht, wie das Unternehmen die Kontrolle behält.
