Browser AI Agent Hijack via Extension: Why Glance Uses Do It, Not Auto-Act

BragJack (2026) showed extensions can force prompts into agentic browsers. Glance is a personal Gmail Do It close: one click, Undo, no auto-send. Not an agentic browser.

Glance · 6 min read

Yes. In September 2026, researchers at Forever Security disclosed BragJack: a single ordinary-looking Chrome extension could hijack built-in AI assistants in five Chromium products by forcing attacker-authored prompts into the agent's privileged channel. They call that technique Prompt Forcing. It is different from classic prompt injection.

That matters because agentic browsers are built to act inside authenticated sessions. If an extension can seize the agent channel, the agent's legitimate privileges become the attack surface.

Glance is a different shape. Glance closes open loops. Gmail is where it starts today: it watches the open thread, surfaces one Do It when a real close is clear, writes where you already work, supports Undo, and stays quiet when unsure. It is not an agentic browser that auto-acts across the web. It is not an email helper, inbox AI, inbox-zero tool, or chat bot. And it does not auto-send as the close model.

Glance next to an agentic browser

  • Job. Agentic browser: Read pages and often act inside authenticated sessions. Glance: Close a clear personal intent from the open Gmail thread.
  • Trigger. Agentic browser: Agent receives prompts / can be driven to act. Glance: One Do It: a human click.
  • Auto-send / auto-act. Agentic browser: Product category often includes acting for you. Glance: No auto-send as the close model.
  • When unsure. Agentic browser: Agent may still be steerable. Glance: Stays quiet.
  • Reversibility. Agentic browser: Varies. Glance: Undo on the write.
  • Product line. Agentic browser: Browser-level agent. Glance: Personal closing, starting in Gmail.

Common questions

Can a Chrome extension hijack a browser AI agent?

Researchers at Forever Security showed in September 2026 (BragJack) that a malicious extension already installed could force prompts into built-in AI assistants in several Chromium browsers. That technique is Prompt Forcing, distinct from classic prompt injection. Keep browsers updated and audit extensions. This was researcher disclosure / PoC framing, not a claim of mass in-the-wild exploitation.

What is Prompt Forcing?

Unlike prompt injection (sneaking text into content the model already reads), Prompt Forcing means the attacker hands the agent the whole instruction and follow-ups, then the agent may carry them out with its existing privileges. Covered by Forever Security (16 Sep 2026) and BleepingComputer (19 Sep 2026).

Is Glance an agentic browser?

No. Glance closes open loops. Gmail is where it starts today: one Do It when a real close is clear, write in place, Undo, quiet when unsure. It is not a browser agent that auto-acts across the web.

Does Glance send email or take actions by itself?

No auto-send as the close model. A human clicks Do It. Writes are designed to be reversible with Undo.
