A draft in the chat

Glance closes open loops. Gmail is where it starts today.

On a one-to-one chat, when someone asks for one place or one fact Glance can already find, Glance can put that answer in the box. You send it. Glance does not press Send, and a draft is not a closed loop.

Each app stays off until you turn it on here. Glance reads only the chat you have open. To name a place, it reads the location of events on the Google calendar you already connected. It does not read event titles. If Google is not connected, it stays quiet.
