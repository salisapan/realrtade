# Glance product lab: proposals

Written by the product-lab routine (Sun + Wed 14:52 Israel, `docs/open-tasks.md` row 64). One file per proposal: `YYYY-MM-DD-<slug>.md`.

Each proposal has a `Status:` line: `proposed` → `approved` or `rejected` (by Sali only) → `experiment built` → `kept`, `iterate` or `dropped` (with the A/B numbers).

Template, one page:
- **Status**, date
- **The gap**: which open loop Glance misses today, with the evidence (holistic close map row, real-mail eval, paid-readiness bar, learning ledger)
- **The user moment**: what the person sees, in one or two sentences
- **How it closes a loop** (ProofOfClose condition)
- **A/B**: variant A (today) vs B (the new), the metric (wrong Do It, missed close, closes per loop), the data set
- **Risks** and what stays locked (no send without a click, silence when unsure, masking)
- **Size**: what one Wednesday can build
